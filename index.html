Project Aim

To detect and prevent cyber attacks on Vehicle CAN Bus network and protect ECUs (Engine, Brakes, Steering) from unauthorized intrusion in real-time.

● Live Project - All Weeks Completed (100%)

Week 1: Setup & CAN Basics ✅ | Week 2: Attack Simulation ✅ | Week 3: ML Detection ✅ | Week 4: Countermeasures ✅ | Final Review ✅

Problem: Modern cars use CAN Bus without built-in security. Any attacker can inject fake messages to control brakes / engine.

Solution: CAN-Sentinel monitors live CAN traffic, detects attacks using Rule + ML, and actively blocks them using Error Frames & Countermeasures.

⚙️ How CAN-Sentinel Works

1. Monitor
Live sniffing on vcan0 using SocketCAN. Captures ID, DLC, Data, Timestamp for every frame.
2. Detect
Rule-based + Isolation Forest ML model checks frequency, entropy & value jumps. 99.6% detection rate.
3. Defend
On attack: Injects CAN Error Frame to destroy malicious packet mid-flight, blocks ID, enters Safe Mode.
4. Display
PyQt5 Dashboard shows live traffic, Threat Level gauge, attacked ECU diagram & alerts.

System now not only DETECTS attacks, it also BLOCKS & RESPONDS.
